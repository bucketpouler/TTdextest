Générer le tableau

Le CSV reprend les 19 talents du modèle, avec une ligne par membre (sauf Odyssey), puis TRUE ou FALSE. Il est produit uniquement après lecture réussie de tous les profils.

Depuis GitHub Pages, la lecture directe peut être bloquée par le navigateur. La méthode Forumactif fonctionne sur le domaine du forum avec ta session connectée.

Prêt.

Comment faire ?

  1. Clique sur Ouvrir Forumactif (nouvel onglet).
  2. Reviens ici et clique sur Copier le script d'extraction.
  3. Dans l'onglet Forumactif, ouvre les outils développeur (F12), onglet Console, colle le script et valide avec Entrée. Si le navigateur bloque le collage, suis la consigne affichée dans sa console.
  4. Une fois les profils analysés, reviens sur cette page : le tableau et le bouton d'export apparaîtront. Si la communication entre onglets est bloquée, le fichier CSV se téléchargera directement depuis Forumactif.

La page nécessite une session Forumactif autorisée à consulter les profils. Aucune donnée n'est envoyée à un serveur tiers : l'analyse s'exécute dans ton navigateur.
